## Selected projects

### Cloud & DevOps

- **[Prometheus-Grafana-Playbooks](https://github.com/hendzormati/Prometheus-Grafana-Playbooks)**  
  Automated deployment of Prometheus, Grafana and Node Exporter with Ansible to monitor OpenStack and Kubernetes infrastructure.

- **[kubernetes-playbooks](https://github.com/hendzormati/kubernetes-playbooks)**  
  Automated Kubernetes cluster deployment with Ansible, supporting single-master and multi-master configurations with HAProxy.

- **[Portfolio](https://github.com/hendzormati/Portfolio)**  
  Personal portfolio landing page, containerized with Docker and deployed automatically through a GitHub Actions CI/CD pipeline.

- **[simple-k8s-mcp-server](https://github.com/hendzormati/simple-k8s-mcp-server)**  
  Lightweight Kubernetes server built in Go, using the Model Context Protocol (MCP) for conversational cluster management.
