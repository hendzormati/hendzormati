## Projets à découvrir

### Cloud & DevOps

- **[Prometheus-Grafana-Playbooks](https://github.com/hendzormati/Prometheus-Grafana-Playbooks)**  
  Déploiement automatisé de Prometheus, Grafana et Node Exporter avec Ansible pour superviser les infrastructures OpenStack et Kubernetes.

- **[kubernetes-playbooks](https://github.com/hendzormati/kubernetes-playbooks)**  
  Automatisation du déploiement de clusters Kubernetes avec Ansible, en configuration single-master ou multi-master avec HAProxy.

- **[Portfolio](https://github.com/hendzormati/Portfolio)**  
  Site de portfolio personnel, conteneurisé avec Docker et déployé automatiquement via un pipeline CI/CD GitHub Actions.

- **[simple-k8s-mcp-server](https://github.com/hendzormati/simple-k8s-mcp-server)**  
  Serveur Kubernetes léger développé en Go, utilisant le Model Context Protocol (MCP) pour rendre la gestion des clusters conversationnelle.

### Développement logiciel

- **[chatbot-api-ensim](https://github.com/hendzormati/chatbot-api-ensim)**  
  Chatbot assistant personnel développé avec Spring Boot, exposant une API REST et interagissant avec Telegram via un système de polling.

- **[2026_4ATechFacHum_ZORMATI_BELHAJSALAH](https://github.com/hendzormati/2026_4ATechFacHum_ZORMATI_BELHAJSALAH)**

- **[Cocorico_RA](https://github.com/hendzormati/Cocorico_RA)**

- **[Cuteness-Overdose-Vr](https://github.com/hendzormati/Cuteness-Overdose-Vr)**  
  Jeu en réalité virtuelle pour Meta Quest 3, développé avec Unity et C#, intégrant interactions physiques, animations et système de score.
